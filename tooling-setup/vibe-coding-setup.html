חשבון GitHub

כ-5 דקות · מי שכבר יש לו חשבון מדלג
ב-GitHub יחיה הקוד של הצוות. במפגש כל צוות פותח ריפו (תיקיית פרויקט בענן) משלו, וכל חברי הצוות עובדים עליו.
  1. היכנסו ל-github.com/signup.
  2. הירשמו עם מייל שאתם נכנסים אליו בקלות. מייל פרטי מתאים.
  3. בחרו שם משתמש מקצועי. הוא נשאר איתכם שנים, ואחרים יראו אותו בפרויקט.
  4. אשרו את המייל ש-GitHub שולח.
⚠️ לא פותחים ריפו עכשיו
את הריפו פותחים ביחד במפגש, אחד לכל צוות. חשבון בלבד מספיק.

התקנת VS Code

כ-5 דקות · מי שכבר התקין מדלג
‏VS Code היא סביבת העבודה שבה נכתוב קוד ונעבוד עם קלוד. היא חינמית, ל-Windows ול-Mac.
  1. היכנסו ל-code.visualstudio.com/download והורידו את הגרסה למערכת שלכם.
  2. ב-Windows: מריצים את קובץ ההתקנה ולוחצים Next עד הסוף. ב-Mac: גוררים את האייקון לתיקיית Applications.
  3. פתחו את VS Code. את מסך ה-Welcome אפשר לסגור.
💡 איפה הטרמינל?
בכל הפקודות במדריך משתמשים בטרמינל של VS Code: בתפריט Terminal בוחרים New Terminal, או לוחצים Ctrl+` (התו שמעל Tab).
3

התקנת Git

כ-5 דקות
‏Git שומר גרסאות של הקוד על המחשב שלכם, ו-GitHub שומר אותן בענן. צריך את שניהם.
🪟 Windows
  1. היכנסו ל-git-scm.com/download/win. ההורדה מתחילה לבד.
  2. מריצים את קובץ ההתקנה ולוחצים Next. ברירות המחדל בסדר.
  3. במסך Adjusting your PATH בוחרים באפשרות Git from the command line and also from 3rd-party software (זו ברירת המחדל).
🍎 Mac
  1. פתחו את הטרמינל של VS Code והקלידו:
    xcode-select --install
  2. בחלון של Apple לוחצים Install ומחכים לסיום, כמה דקות.
  3. אם מופיעה הודעה שהכלים כבר מותקנים, הכול בסדר וממשיכים.
🐧 Linux
  1. באובונטו או דביאן, בטרמינל:
    sudo apt install git
  2. בפדורה:
    sudo dnf install git

בדיקת Git, ושם ומייל

כ-3 דקות · לא לדלג
כל שמירה של קוד (commit) נושאת שם ומייל. בלי ההגדרה הזו Git לא יודע מי אתם.
  1. סגרו את VS Code ופתחו אותו מחדש, כדי שיכיר את ההתקנה.
  2. בטרמינל של VS Code:
    git --version
    צריך לקבל שורה כמו git version 2.51.0. המספר יכול להיות אחר.
  3. הגדירו שם (החליפו בשם שלכם):
    git config --global user.name "Your Name"
  4. הגדירו מייל, אותו מייל שאיתו נרשמתם ל-GitHub:
    git config --global user.email "you@example.com"
⚠️ קיבלתם command not found או "not recognized"?
‏Git לא מותקן או שהמחשב עוד לא מכיר אותו. סגרו את VS Code לגמרי ופתחו מחדש. ב-Windows, אם זה עדיין לא עובד, הפעילו מחדש את המחשב. ב-Mac, חזרו לשלב 3 וודאו שההתקנה הסתיימה.

התוסף של Claude Code ב-VS Code

כ-3 דקות · רק התקנה, ההתחברות במפגש
‏Claude Code הוא הסוכן שיעבוד איתכם בתוך VS Code: קורא את הקבצים בפרויקט, כותב קוד ומריץ פקודות, ומבקש אישור לפני כל פעולה.
  1. ב-VS Code לחצו על אייקון התוספים בסרגל הצד, זה עם ארבעה ריבועים. קיצור מקלדת: Ctrl+Shift+X, וב-Mac Cmd+Shift+X.
  2. חפשו Claude Code, בחרו את התוסף של Anthropic, ולחצו Install.
  3. אחרי ההתקנה מופיע אייקון הניצוץ של Claude בסרגל הצד, ובפינה התחתונה של החלון מופיע ✻ Claude Code.
ℹ️ מתי מתחברים?
ההזמנה למנוי של הקורס נשלחת לכתובת האוניברסיטאית שלכם, ונתחבר ביחד במפגש. מי שיש לו מנוי פרטי בתשלום (Pro או Max) יכול להתחבר כבר עכשיו. חשבון חינמי (Free) לא כולל את Claude Code.
