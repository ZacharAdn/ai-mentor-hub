חשבון GitHub + הצטרפות לארגון של הקורס

כ-5 דקות
GitHub זה המקום שבו הקוד שלכם יחיה. כל הפרויקטים שלכם בקורס נחים תחת הארגון Geo-AI-Course — לשם תדחפו את הקוד לאורך כל המודול.

עקבו אחרי השלבים:

  1. גשו ל-github.com/signup.
  2. הירשמו עם המייל שאיתו אתם רשומים בקורס — זה המייל שאליו אנחנו שולחים את ההזמנה לארגון ואת רישיון Anthropic.
  3. בחרו username מקצועי — זה נשאר איתכם הרבה שנים, אז להימנע מ-cool_dude_2003.
  4. אשרו את המייל שיגיע מ-GitHub.
  5. פתחו את ההזמנה לארגון שתגיע במייל — היא נראית: "@ZacharAdn has invited you to join @Geo-AI-Course". לחצו על הלינק ואשרו.
  6. וודאו שאתם רואים את github.com/Geo-AI-Course בחשבון שלכם.
⚠️ למה דווקא המייל הרשום בקורס?
כל המערכות של הקורס (GitHub, Anthropic Team) מסונכרנות לפי המייל הזה. אם תירשמו עם מייל אחר — לא תקבלו את ההזמנות והרישיונות, ויהיה צורך לפתור ידנית.
ℹ️ עוד לא קיבלתם הזמנה?
אם הגעתם למפגש הראשון בלי הזמנה במייל — אל תיתקעו. סיימו את שאר השלבים (VS Code + Git), וזכר יוסיף אתכם בלייב במהלך הסדנה.

התקנת VS Code (סביבת הפיתוח)

כ-5 דקות
VS Code (Visual Studio Code) זו סביבת הפיתוח החינמית של מיקרוסופט — הכלי הכי פופולרי לעבודה עם קוד. אם כבר התקנתם — תדלגו לשלב הבא.

עקבו אחרי השלבים:

  1. גשו ל-code.visualstudio.com/download
  2. בחרו את הגרסה למערכת ההפעלה שלכם (Mac / Windows / Linux) ולחצו Download.
  3. פתחו את קובץ ההתקנה מתיקיית ההורדות. Windows: Next-Next-Next. Mac: גוררים את האייקון לתיקיית Applications.
  4. פתחו את VS Code לפעם הראשונה. אפשר לסגור את ה-Welcome.
💡 הכרת הפאנלים
בצד שמאל יש כמה אייקונים: Explorer (קבצים) · Search (חיפוש) · Source Control (Git GUI, אייקון של ענף) · Extensions (תוספים). את הטרמינל התחתון פותחים עם Ctrl+` (בק-טיק).

התקנת Git

כ-5 דקות
Git זה התוכנה שמנהלת גרסאות של הקוד שלכם. Git ≠ GitHub: Git רץ על המחשב, GitHub זה שרת ענן. שניהם עובדים ביחד.

בחרו את מערכת ההפעלה שלכם:

🪟 Windows
  1. גשו ל-git-scm.com/download/win — ההורדה תתחיל אוטומטית.
  2. פתחו את קובץ ההתקנה והריצו אותו.
  3. Next-Next-Next — ברירות המחדל בסדר. חשוב: במסך "Adjusting your PATH" — בחרו "Git from the command line and also from 3rd-party software".
  4. סיימו את ההתקנה.
הורדה והתקנה של Git לווינדוס
🍎 Mac
  1. פתחו טרמינל (Spotlight → Terminal). הקלידו:
    xcode-select --install
  2. ייפתח דיאלוג של Apple — לחצו Install וחכו לסיום (3-5 דק').
🐧 Linux
  1. פתחו טרמינל. Ubuntu/Debian: sudo apt install git. Fedora: sudo dnf install git
4

אימות — האם Git באמת מותקן?

כ-1 דקה
אסור לדלג. אפשר להיות בלי Git על המחשב, גם אם נדמה שמותקן — וכל ה-flow ייפול בשלב הבא. בודקים עכשיו.

עקבו אחרי השלבים:

  1. פתחו את VS Code (אם עוד לא פתוח).
  2. פתחו את הטרמינל הפנימי — Ctrl+` (בק-טיק, התו מעל ה-Tab).
  3. הקלידו:
    git --version
  4. צריך לקבל משהו כמו git version 2.43.0 (המספר עשוי להשתנות).
⚠️ אם קיבלתם command not found
סימן ש-Git לא מותקן או לא ב-PATH. Mac: חזרו לשלב 3, וודאו ש-xcode-select --install הסתיים. Windows: סגרו את VS Code, פתחו אותו מחדש — אם עדיין לא עובד, restart למחשב כדי שה-PATH יתעדכן.

קונפיגורציית Git — שם ומייל

כ-2 דקות
כל commit שאתם תעשו יישא את השם והמייל שלכם. בלי הקינפוג הזה, Git לא יודע מי אתם וה-commits לא ייוחסו לחשבון שלכם בגרף התרומות ב-GitHub.

עקבו אחרי השלבים:

  1. בטרמינל הפנימי של VS Code, הקלידו (החליפו "השם שלך" בשם שלכם):
    git config --global user.name "השם שלך"
  2. אחר כך, הקלידו (החליפו במייל שאיתו נרשמתם ל-GitHub):
    git config --global user.email "your-email@example.com"
  3. בדיקה — שתי השורות תופיעו ב:
    git config --global --list
💡 למה --global?
--global אומר ל-Git להחיל את ההגדרה על כל ה-repos במחשב — פעם אחת לכל החיים, לא צריך לחזור על זה לכל פרויקט.
⚠️ המייל חייב להתאים ל-GitHub
המייל חייב להיות זהה למייל שאיתו נרשמתם ל-GitHub. אם הוא שונה — ה-commits לא ייוחסו לכם בגרף התרומות.

התקנת Claude Code Extension

כ-5 דקות
Claude Code זה הסוכן של Anthropic שיעבוד איתכם בתוך VS Code. סוכן = כלי AI שיכול לקרוא קבצים (Read), לכתוב קבצים (Write), ולהריץ פקודות בטרמינל (Bash). אחרי ההתקנה תראו אותו בצד ימין של VS Code.

עקבו אחרי השלבים:

  1. קודם כל — וודאו שקיבלתם הזמנה ל-Anthropic Team במייל (זכר שלח). לחצו על הלינק במייל ואשרו רישום.
  2. ב-VS Code: לחצו על אייקון ה-Extensions בצד שמאל (4 ריבועים) או Cmd/Ctrl + Shift + X.
  3. בשורת החיפוש למעלה — חפשו "Claude Code".
  4. בחרו את ה-extension הראשון (של Anthropic, סימן וי כחול ליד השם) ולחצו Install.
  5. אחרי ההתקנה תראו את ה-icon של Claude בעורך — אבל רק אחרי שתפתחו קובץ כלשהו (README, CSV, או כל קובץ אחר). פתחו קובץ קיים מ-Explorer, או צרו חדש (File → New File), והאייקון יופיע מיד.
  6. לחצו על האייקון — VS Code יבקש מכם להתחבר. תאשרו, הוא יפתח דפדפן עם דף Anthropic, תאשרו, חוזרים ל-VS Code.
  7. לסשן חדש: Cmd/Ctrl + Esc או לחצו על ה-icon של Claude.
חלונית Extensions עם התוסף Claude Code for VS Code
אייקון Claude ב-VS Code (מופיע רק אחרי פתיחת קובץ)
💡 @-mention להקשר
בתוך השיחה עם Claude, אפשר להקליד @ ולבחור קובץ — והסוכן יקרא אותו כהקשר. דוגמה: @README.md תכתוב לי FEATURE_PLAN.md לפי הפרויקט הזה.
💡 פרומפט ממוספר
כשמבקשים מהסוכן משהו מורכב, עדיף לפרק לרשימה ממוספרת:
תכתוב README: 1. שיהיה באנגלית 2. שיכלול את הסעיפים: Problem, Target Users, Data Source, ML Approach 3. שורת תיאור אחת בהתחלה
⚠️ אם הסוכן הציע פקודה לטרמינל
הסוכן יבקש מכם הרשאה לכל פעולה — קראו לפני שאתם מאשרים. במיוחד בפקודות git push: תעדיפו לעשות commit + push דרך ה-Source Control GUI כדי שאתם בשליטה, לא הסוכן.

הגדרות מתקדמות — API key, פרטיות, אובייקטיביות

~5 דקות · אופציונלי
שלוש הגדרות שכדאי לדעת מהיום הראשון: איך משתמשים ב-API key הגיבוי, איך לבטל איסוף שיחות לאימון, ואיך לגרום ל-Claude להיות יותר ישר ולא חנפן.
🔑 מפתחות API ($25 גיבוי) — יישלחו במייל במהלך השבוע

במהלך השבוע נשלח לכם מפתח API של Anthropic ישירות במייל (יחד עם הזמנת ה-Team). זה ה-גיבוי: עבודה יומיומית על מנוי Claude Team, וכשמגיעים לתקרת ה-usage (שעה/שבוע) — מפעילים את ה-API key.

⚠️ ההקצאה שלכם: $25 לחודש קשיח (per workspace). זה נשרף מהר ממה שחושבים — יכול להיגמר תוך פחות מסשן עבודה של 5 שעות אם עובדים אינטנסיבית. שימו לב.

איך מפעילים — 3 צעדים בטרמינל (לא צריך להיכנס לאף אתר):

  1. קחו את ה-key מהמייל שתקבלו (נראה sk-ant-api03-...).
  2. פתחו את הטרמינל הפנימי של VS Code (Ctrl+`) והדביקו:
    export ANTHROPIC_API_KEY=sk-ant-api03-XXXX...
  3. פתחו סשן Claude Code חדש. מהרגע הזה — האימות מול ה-API שלכם, וכל שימוש שחורג מה-Team ייגבה מ-$25 הסל.

בדיקת usage בכל זמן: בתוך סשן Claude Code הקלידו /cost — תראו כמה דולרים נצרכו.

💡 (אופציונלי) לקבע את ה-API key לטרמינלים עתידיים

לא חובה. בלי הצעד הזה, ה-export תקף רק לטרמינל הנוכחי — כשתפתחו טרמינל חדש תצטרכו לחזור על השורה. אם אתם משתמשים ב-API key באופן קבוע, נוח לקבע אותו:

Mac / Linux: פתחו את ~/.zshrc (או ~/.bashrc) והוסיפו את שורת ה-export בסוף הקובץ. הפעילו טרמינל חדש, או הריצו:

source ~/.zshrc

Windows: Search → "Environment Variables" → New System Variable → Name: ANTHROPIC_API_KEY → Value: ה-key שלכם. סגרו ופתחו מחדש את VS Code.

🔒 לבטל איסוף שיחות לאימון Claude

כברירת מחדל, השיחות שלכם עם Claude עשויות לשמש לשיפור המודל. אם אתם עובדים עם דאטה רגיש (חברה / לקוחות / סודי):

  1. היכנסו ל-claude.ai ולחצו על אייקון הפרופיל (פינה ימנית-עליונה).
  2. Settings → לשונית Privacy.
  3. כבו את "Help improve Claude".

מהרגע הזה — השיחות שלכם נשארות פרטיות ולא ישמשו לאימון.

🎯 לקבל ביקורת אמיתית — להוריד את החנפנות

זו לא נטייה ייחודית של Claude — כל ה-LLMs נוטים להסכים עם המשתמש ולהחמיא (sycophancy). הדרך למזער את זה ב-Claude — שתי אפשרויות:

  1. בתוך שיחה עם Claude Code: תגידו לו לזכור את ההנחיה למטה תמיד — הוא יוסיף אותה ל-CLAUDE.md הגלובלי שלכם, וזה ישפיע על כל הסשנים העתידיים.
  2. ב-claude.ai או Claude Desktop: Settings → General → Instructions for Claude → הדביקו את ההנחיה.

ההנחיה (להעתקה):

Never tell me what I want to hear. I want you to look at things objectively, contradict me when needed. If you think otherwise, go with your strong opinion.

2.1

בחירת פרויקט + דאטה

~5 דקות לחשיבה
לפני שמתחילים לקודד — בוחרים נושא ודאטה. הקורס מציע שלוש רמות בשלות (data maturity); בחרו את הרמה שמתאימה לזמן והשאיפות שלכם.

שלוש הרמות:

  1. Descriptive — מתאר נתונים. EDA, dashboards, מפות. דוגמה: מפה של תאונות דרכים לפי אזור.
  2. Predictive — חוזה עתיד. מודל ML שמנבא תוצאות. דוגמה: ניבוי איפה תאונות עתידיות יקרו.
  3. Prescriptive — סוכן שעושה פעולות. מערכת אוטונומית שפועלת לטובת המטרה. דוגמה: שליטה ברמזורים בזמן אמת למניעת תאונות.
💡 איזה רמה לבחור?
שואפים ל-Level 2 כמינימום. אם זה מרגיש גדול מדי — Level 1 גם בסדר לחלוטין. המטרה: לתת ערך אמיתי למישהו אמיתי (אתם, עמית בעבודה, צוות, ארגון).
ℹ️ צריכים עזרה במציאת רעיון או דאטה?
מחר נשתף כאן קישור לצ'אטבוט עזר שיעזור לכם לבחור נושא ולמצוא דאטה רלוונטי. בינתיים — חשבו על תחום שמעניין אתכם או על דאטה שיש לכם כבר (אקדמי, מעבודה, ציבורי).
💡 קריטריונים לדאטה טוב
  • גיאוגרפי — קואורדינטות, גבולות, או מיקום מהותי לבעיה.
  • מספיק שורות — לפחות כמה מאות לרמה 1, אלפים+ לרמה 2.
  • אתם יכולים להסביר את המטרה — אם אתם לא יודעים מה אתם רוצים מהדאטה, גם הסוכן לא יידע.
2.2

הפוש הראשון לארגון

~10 דקות
זה הרגע שבו הכל מתחבר: לוקחים repo שקיים תחת Geo-AI-Course, מורידים עותק למחשב, ודוחפים בחזרה את ה-README הראשון שלכם. הכל דרך ה-GUI של VS Code — לא טרמינל.

שלב 0 — לוודא שיש לכם repo בארגון:

  1. היכנסו ל-github.com/Geo-AI-Course ובדקו אם יש לכם שם repo מוכן (זכר עשוי להקים מראש לכל זוג).
  2. אין לכם repo? בדף הארגון, לחצו על הכפתור הירוק New repository (פינה ימנית-עליונה). שם תיאורי (לדוגמה geoai-project-tlv-bike-flow), בחירה Public/Private לפי הנחיית זכר, סמנו Add a README file, ולחצו Create repository.

Clone — להוריד את ה-repo למחשב:

  1. בדף ה-repo ב-Geo-AI-Course, לחצו על הכפתור הירוק Code → העתיקו את ה-HTTPS URL.
  2. ב-VS Code: Cmd/Ctrl + Shift + P → הקלידו "Git: Clone" → הדביקו את ה-URL.
  3. בחרו תיקיית יעד במחשב (Desktop / Documents — מה שנוח).
  4. כשהורדה הסתיימה, לחצו Open Folder. התיקייה תיטען ב-Explorer.

עריכה + commit + push דרך ה-GUI:

  1. פתחו את README.md ב-Editor (אם אין — צרו חדש: File → New File, שמרו כ-README.md).
  2. הוסיפו שורה: שם הפרויקט + משפט תיאור.
  3. שמרו (Cmd/Ctrl + S).
  4. פתחו את Source Control (אייקון הענף בצד שמאל). תראו את README תחת Changes.
  5. לחצו על + ליד הקובץ — Stage.
  6. בשדה הטקסט למעלה — כתבו הודעת commit (למשל: docs: add project description).
  7. לחצו ✓ Commit.
  8. לחצו 🔄 Sync Changes — זה Pull + Push.
  9. רעננו את דף ה-GitHub בדפדפן — הקובץ אמור להופיע ✅
פאנל Source Control עם כפתור Stage (+)
תפריט ה-Commit עם אופציית Sync
⚠️ Clone — לא Publish!
אם VS Code מציע "Publish to GitHub" — אל תלחצו. זה יוצר repo חדש בחשבון הפרטי שלכם, לא בארגון. בחזרה ל-Cmd/Ctrl + Shift + P וחפשו את "Git: Clone" במדויק.
⛔ אל תלחצו על זה — Publish to GitHub יוצר ב-repo הפרטי שלכם
⚠️ אין לי הרשאת יצירת repos בארגון
כשתלחצו New repository ב-Geo-AI-Course — אם הארגון לא מופיע כבעלים אפשרי, סימן שעוד לא קיבלתם הרשאה. בקשו מזכר להוסיף אתכם — הוא יוסיף בלייב במהלך הסדנה.
⚠️ דחפתי בטעות לחשבון הפרטי שלי — מה עכשיו?

איך מזהים — שתי דרכים:

  1. URL בדפדפן: אם הוא github.com/<your-username>/... במקום github.com/Geo-AI-Course/... — ה-repo נחת בחשבון הפרטי שלכם.
  2. מ-VS Code ישירות (ללא דפדפן): בפאנל Source Control, רחפו עם העכבר מעל הקומיט האחרון בגרף → המתינו ~3 שניות → ייפתח tooltip עם פרטי הקומיט וכפתור Open on GitHub. לחיצה תפתח את ה-repo בדפדפן — תראו מיד היכן הקומיט נחת.
Hover על קומיט ב-Source Control → Open on GitHub

הקבצים שכתבתי לא בסכנה: ה-Clone של ה-repo הנכון יוצר תיקייה חדשה לגמרי במחשב. התיקייה הישנה שלכם (עם ה-README שכתבתם) נשארת שלמה — שום דבר לא נמחק.

איך מתקנים (הדרך הקלה — מומלץ):

  1. היכנסו ל-repo הפרטי ב-GitHub → Settings → Danger Zone → Delete this repository (מקלידים את שם ה-repo לאישור).
  2. בדף הארגון Geo-AI-Course, יוצרים repo חדש (כפי שמתואר בשלב 0 למעלה).
  3. ב-VS Code: Cmd/Ctrl + Shift + P → "Git: Clone" ל-תיקייה חדשה (לא לתיקייה הישנה!).
  4. העתיקו את ה-README (וקבצים נוספים) מהתיקייה הישנה לתיקייה החדשה שנוצרה ב-Clone.
  5. Source Control: Stage → Commit → Sync. ה-README שלכם עולה ל-repo הנכון בארגון ✅

אלטרנטיבה (Transfer): ב-Settings של ה-repo הפרטי → Transfer ownership → הקלידו Geo-AI-Course. חוסך את צעדי 3-4, אבל דורש שתבדקו אחרי שה-remote של ה-repo המקומי שלכם הצביע לארגון.
