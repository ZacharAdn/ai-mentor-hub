חשבון GitHub + הצטרפות לארגון של הקורס

כ-5 דקות
GitHub זה המקום שבו הקוד שלכם יחיה. כל הפרויקטים שלכם בקורס נחים תחת הארגון Geo-AI-Course — לשם תדחפו את הקוד לאורך כל המודול.

עקבו אחרי השלבים:

  1. גשו ל-github.com/signup.
  2. הירשמו עם המייל שאיתו אתם רשומים בקורס — זה המייל שאליו אנחנו שולחים את ההזמנה לארגון ואת רישיון Anthropic.
  3. בחרו username מקצועי — זה נשאר איתכם הרבה שנים, אז להימנע מ-cool_dude_2003.
  4. אשרו את המייל שיגיע מ-GitHub.
  5. פתחו את ההזמנה לארגון שתגיע במייל — היא נראית: "@ZacharAdn has invited you to join @Geo-AI-Course". לחצו על הלינק ואשרו.
  6. וודאו שאתם רואים את github.com/Geo-AI-Course בחשבון שלכם.
⚠️ למה דווקא המייל הרשום בקורס?
כל המערכות של הקורס (GitHub, Anthropic Team) מסונכרנות לפי המייל הזה. אם תירשמו עם מייל אחר — לא תקבלו את ההזמנות והרישיונות, ויהיה צורך לפתור ידנית.
ℹ️ עוד לא קיבלתם הזמנה?
אם הגעתם למפגש הראשון בלי הזמנה במייל — אל תיתקעו. סיימו את שאר השלבים (VS Code + Git), וזכר יוסיף אתכם בלייב במהלך הסדנה.
2

התקנת VS Code (סביבת הפיתוח)

כ-5 דקות
VS Code (Visual Studio Code) זו סביבת הפיתוח החינמית של מיקרוסופט — הכלי הכי פופולרי לעבודה עם קוד. אם כבר התקנתם — תדלגו לשלב הבא.

עקבו אחרי השלבים:

  1. גשו ל-code.visualstudio.com/download
  2. בחרו את הגרסה למערכת ההפעלה שלכם (Mac / Windows / Linux) ולחצו Download.
  3. פתחו את קובץ ההתקנה מתיקיית ההורדות. Windows: Next-Next-Next. Mac: גוררים את האייקון לתיקיית Applications.
  4. פתחו את VS Code לפעם הראשונה. אפשר לסגור את ה-Welcome.
💡 הכרת הפאנלים
בצד שמאל יש כמה אייקונים: Explorer (קבצים) · Search (חיפוש) · Source Control (Git GUI, אייקון של ענף) · Extensions (תוספים). את הטרמינל התחתון פותחים עם Ctrl+` (בק-טיק).
3

התקנת Git

כ-5 דקות
Git זה התוכנה שמנהלת גרסאות של הקוד שלכם. Git ≠ GitHub: Git רץ על המחשב, GitHub זה שרת ענן. שניהם עובדים ביחד.

בחרו את מערכת ההפעלה שלכם:

🍎 Mac
  1. פתחו טרמינל (Spotlight → Terminal). הקלידו:
    xcode-select --install
  2. ייפתח דיאלוג של Apple — לחצו Install וחכו לסיום (3-5 דק').
🪟 Windows
  1. גשו ל-git-scm.com/download/win — ההורדה תתחיל אוטומטית.
  2. פתחו את קובץ ההתקנה והריצו אותו.
  3. Next-Next-Next — ברירות המחדל בסדר. חשוב: במסך "Adjusting your PATH" — בחרו "Git from the command line and also from 3rd-party software".
  4. סיימו את ההתקנה.
🐧 Linux
  1. פתחו טרמינל. Ubuntu/Debian: sudo apt install git. Fedora: sudo dnf install git
4

אימות — האם Git באמת מותקן?

כ-1 דקה
אסור לדלג. אפשר להיות בלי Git על המחשב, גם אם נדמה שמותקן — וכל ה-flow ייפול בשלב הבא. בודקים עכשיו.

עקבו אחרי השלבים:

  1. פתחו את VS Code (אם עוד לא פתוח).
  2. פתחו את הטרמינל הפנימי — Ctrl+` (בק-טיק, התו מעל ה-Tab).
  3. הקלידו:
    git --version
  4. צריך לקבל משהו כמו git version 2.43.0 (המספר עשוי להשתנות).
⚠️ אם קיבלתם command not found
סימן ש-Git לא מותקן או לא ב-PATH. Mac: חזרו לשלב 3, וודאו ש-xcode-select --install הסתיים. Windows: סגרו את VS Code, פתחו אותו מחדש — אם עדיין לא עובד, restart למחשב כדי שה-PATH יתעדכן.
5

קונפיגורציית Git — שם ומייל

כ-2 דקות
כל commit שאתם תעשו יישא את השם והמייל שלכם. בלי הקינפוג הזה, Git לא יודע מי אתם וה-commits לא ייוחסו לחשבון שלכם בגרף התרומות ב-GitHub.

עקבו אחרי השלבים:

  1. בטרמינל הפנימי של VS Code, הקלידו (החליפו "השם שלך" בשם שלכם):
    git config --global user.name "השם שלך"
  2. אחר כך, הקלידו (החליפו במייל שאיתו נרשמתם ל-GitHub):
    git config --global user.email "your-email@example.com"
  3. בדיקה — שתי השורות תופיעו ב:
    git config --global --list
💡 למה --global?
--global אומר ל-Git להחיל את ההגדרה על כל ה-repos במחשב — פעם אחת לכל החיים, לא צריך לחזור על זה לכל פרויקט.
⚠️ חשוב
המייל חייב להיות זהה למייל שאיתו נרשמתם ל-GitHub. אם הוא שונה — ה-commits לא ייוחסו לכם בגרף התרומות.
6

הפרויקט הראשון שלכם + push ל-GitHub

כ-10 דקות
זה הרגע שבו הכל מתחבר: יוצרים פרויקט, עושים commit ראשון, ודוחפים ל-GitHub תחת הארגון Geo-AI-Course. הכל דרך ה-GUI של VS Code — לא טרמינל.
ℹ️ שני מסלולים — זכר יגיד לכם איזה רלוונטי לכם
תלוי איך הוחלט להקים repos: או שכבר יש לכם repo מוכן בארגון (מסלול A — Clone), או שאתם יוצרים בעצמכם תחת הארגון (מסלול B — Publish). הצעדים שונים — תעקבו רק אחרי המסלול שלכם.
מסלול A Clone — יש לי repo מוכן בארגון
קיבלתם הזמנה ל-repo ספציפי תחת Geo-AI-Course (זכר הקים אותו עבורכם). מורידים עותק → עורכים → דוחפים בחזרה.

Clone — להוריד עותק:

  1. ב-GitHub, היכנסו ל-repo שלכם תחת Geo-AI-Course. לחצו על הכפתור הירוק Code → העתיקו את ה-HTTPS URL.
  2. ב-VS Code: Cmd/Ctrl + Shift + P → הקלידו "Git: Clone" → הדביקו את ה-URL.
  3. בחרו תיקיית יעד במחשב (Desktop / Documents — מה שנוח).
  4. כשהורדה הסתיימה, לחצו Open Folder. התיקייה תיטען ב-Explorer.
⚠️ Clone — לא Publish!
אם VS Code מציע "Publish to GitHub" במסלול הזה — אל תלחצו. זה יוצר repo חדש בחשבון הפרטי שלכם במקום לעבוד עם זה שכבר קיים בארגון.

עריכה + commit + push דרך ה-GUI:

  1. פתחו את README.md ב-Editor (אם אין — צרו אחד חדש: File → New File, שמרו כ-README.md).
  2. הוסיפו שורה: שם הפרויקט + משפט תיאור.
  3. שמרו (Cmd/Ctrl + S).
  4. פתחו את Source Control (אייקון הענף בצד שמאל). תראו את README תחת Changes.
  5. לחצו על + ליד הקובץ — Stage.
  6. בשדה הטקסט למעלה — כתבו הודעת commit (למשל: docs: add project description).
  7. לחצו ✓ Commit.
  8. לחצו 🔄 Sync Changes — זה Push + Pull.
  9. רעננו את דף ה-GitHub בדפדפן — הקובץ אמור להופיע ✅
מסלול B Publish — אני יוצר/ת repo חדש בארגון
יש לכם הרשאת יצירת repos בארגון Geo-AI-Course. יוצרים תיקייה מקומית, מוסיפים README, ודוחפים ל-GitHub בלחיצה אחת.

יצירת פרויקט מקומי:

  1. במחשב — צרו תיקייה חדשה במקום נוח (Desktop / Documents). שם לדוגמה: my-first-geoai.
  2. ב-VS Code: File → Open Folder → בחרו את התיקייה שיצרתם.
  3. ב-Explorer (סרגל שמאל) → לחצו על אייקון New File → שם הקובץ: README.md.
  4. הוסיפו שורה: שם הפרויקט + משפט תיאור. שמרו (Cmd/Ctrl + S).

Publish ל-GitHub תחת הארגון:

  1. פתחו את Source Control (אייקון הענף בצד שמאל).
  2. לחצו Initialize Repository — זה יוצר git מקומי.
  3. תראו את README תחת Changes. לחצו + ליד הקובץ (Stage), כתבו הודעת commit (למשל: initial commit), ולחצו ✓ Commit.
  4. Cmd/Ctrl + Shift + P → הקלידו "Publish to GitHub".
  5. חשוב: כשנשאלים לאיזה חשבון לפרסם — בחרו Geo-AI-Course (לא את החשבון הפרטי שלכם).
  6. בחרו "Publish to GitHub public repository" או private לפי הנחיית זכר.
  7. VS Code יפתח את ה-repo בדפדפן ✅
⚠️ אם לא רואים את הארגון ברשימה
סימן שעוד אין לכם הרשאת יצירת repos ב-Geo-AI-Course, או שעוד לא קיבלתם הזמנה. בקשו מזכר להוסיף אתכם, או עברו זמנית למסלול A אחרי שהוא יכין לכם repo.
💡 בפעם הראשונה — אימות GitHub
בפעולה הראשונה מול GitHub (Clone / Sync / Publish), VS Code יפתח דפדפן ויבקש לאשר את החיבור. תאשרו פעם אחת — מאותו רגע, החיבור פעיל.
7

התקנת Claude Code Extension

כ-5 דקות
Claude Code זה הסוכן של Anthropic שיעבוד איתכם בתוך VS Code. סוכן = כלי AI שיכול לקרוא קבצים (Read), לכתוב קבצים (Write), ולהריץ פקודות בטרמינל (Bash). אחרי ההתקנה תראו אותו בצד ימין של VS Code.

עקבו אחרי השלבים:

  1. קודם כל — וודאו שקיבלתם הזמנה ל-Anthropic Team במייל (זכר שלח). לחצו על הלינק במייל ואשרו רישום.
  2. ב-VS Code: לחצו על אייקון ה-Extensions בצד שמאל (4 ריבועים) או Cmd/Ctrl + Shift + X.
  3. בשורת החיפוש למעלה — חפשו "Claude Code".
  4. בחרו את ה-extension הראשון (של Anthropic, סימן וי כחול ליד השם) ולחצו Install.
  5. אחרי ההתקנה תראו את ה-icon של Claude למטה ב-status bar או בסרגל הצד.
  6. לחצו עליו — VS Code יבקש מכם להתחבר. תאשרו, הוא יפתח דפדפן עם דף Anthropic, תאשרו, חוזרים ל-VS Code.
  7. לסשן חדש: Cmd/Ctrl + Esc או לחצו על ה-icon של Claude.
💡 @-mention להקשר
בתוך השיחה עם Claude, אפשר להקליד @ ולבחור קובץ — והסוכן יקרא אותו כהקשר. דוגמה: @README.md תכתוב לי FEATURE_PLAN.md לפי הפרויקט הזה.
💡 פרומפט ממוספר
כשמבקשים מהסוכן משהו מורכב, עדיף לפרק לרשימה ממוספרת:
תכתוב README: 1. שיהיה באנגלית 2. שיכלול את הסעיפים: Problem, Target Users, Data Source, ML Approach 3. שורת תיאור אחת בהתחלה
⚠️ אם הסוכן הציע פקודה לטרמינל
הסוכן יבקש מכם הרשאה לכל פעולה — קראו לפני שאתם מאשרים. במיוחד בפקודות git push: תעדיפו לעשות commit + push דרך ה-Source Control GUI כדי שאתם בשליטה, לא הסוכן.
