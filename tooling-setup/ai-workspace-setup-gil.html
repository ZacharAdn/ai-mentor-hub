מה עושים כאן, ולמה

כלי אחד להתקנה: אובסידיאן - המחברת החכמה שתשמש כזיכרון של המערכת. קלוד דסקטופ כבר מותקן אצלך, אז ראינו אותו יחד במפגש - הוא מופיע כאן רק לשלמות. זה כל מה שצריך. שלב 2 למטה הוא טכני, הוא נעשה איתי במפגשים, ולא בטוח שתצטרך אותו בכלל.

שלב 1 להתקנה עכשיו
שני הכלים שאיתם נתחיל במפגש הראשון.
1

התקנת קלוד דסקטופ

כ-5 דקות
קלוד דסקטופ היא האפליקציה הרשמית של Claude למחשב. זו תהיה נקודת המפגש היומית שלך עם הסוכן. יש לך כבר מנוי לקלוד, אז רק נתקין ונתחבר.

עקוב אחרי השלבים:

  1. פתח את הקישור claude.ai/download (נפתח בטאב חדש)
  2. הורד את הגרסה למחשב שלך: macOS אם זה מק, Windows אם זה חלונות
  3. הרץ את הקובץ שהורדת. במק: גרור את האייקון לתיקיית Applications. בחלונות: לחץ על הקובץ ואשר את ההתקנה
  4. פתח את קלוד דסקטופ, ולחץ Sign in
  5. התחבר עם אותו חשבון שבו אתה כבר משתמש במנוי שלך
איך יודעים שזה עבד?

נפתח חלון צ'אט של קלוד ישירות מהמחשב, בלי דפדפן. נסה לכתוב לו "שלום" ולראות שהוא עונה.

2

התקנת אובסידיאן

כ-5 דקות
אובסידיאן היא מחברת דיגיטלית שמורכבת מקבצים פשוטים במחשב שלך. אנחנו נשתמש בה כ"זיכרון" של המערכת: כאן יישמרו הנתונים, ההגדרות והידע שהסוכן צובר. הכל נשאר אצלך במחשב.

עקוב אחרי השלבים:

  1. פתח את הקישור obsidian.md (נפתח בטאב חדש), ולחץ על כפתור ההורדה הגדול
  2. ההורדה מזהה לבד את סוג המחשב שלך. הרץ את הקובץ שהורד ואשר את ברירות המחדל
  3. פתח את אובסידיאן. במסך הפתיחה בחר Open folder as vault (פתיחת תיקייה קיימת ככספת) - לא Create new vault
  4. נווט אל התיקייה שהכנו יחד במפגש (זו שקלוד יצר), בחר אותה ואשר
  5. זהו - אובסידיאן מציג את התיקייה הקיימת, וכל מה שקלוד יוצר בה מופיע אצלך אוטומטית
מה זו "כספת" (vault)?

פשוט תיקייה במחשב שאובסידיאן מנהל. כל מה שנכתוב שם הוא קבצים רגילים שלך, לא בענן של אף אחד. אתה הבעלים המלא של הזיכרון הזה.

מצוין, סיימת את שלב 1

קלוד דסקטופ ואובסידיאן מותקנים. זה כל מה שצריך למפגש הראשון.

מניעת הטיות: אצלך זה כבר סגור

אפס
כאן היה אמור לשבת פרומפט שמבקש מקלוד להיות אובייקטיבי. אצלך הוא מיותר. מסמך ההוראות שלך למניעת הטיות חזק ממה שהייתי נותן לך, ואתה צדקת במפגש כשאמרת שבקשה מנומסת לאובייקטיביות היא לא מספיק חזקה.
מה כן נעשה עם זה

נעבור עליו יחד במפגש. אני רוצה להראות לך איפה אפשר לחזק אותו עוד: לא בניסוח, אלא במבנה. סוכן שמקבל תפקיד של תוקף התזה, ושלא יודע מראש מה הפוזיציה שלך, מוטה פחות מסוכן שמתבקש יפה להיות הוגן.

שמור שהמידע שלך פרטי

דקה
כברירת מחדל, השיחות שלך עשויות לשמש לשיפור המודל. אתה עובד עם נתוני תיק אישיים, אז כדאי לכבות את זה.

עקוב אחרי השלבים:

  2. עבור ללשונית Privacy (פרטיות)
  3. כבה את האפשרות Help improve Claude. זהו, הנתונים שלך נשארים פרטיים

מה זה, ולמה זה כאן

ההתקנות בשלב הזה הן Node.js (מנוע הרצה), Claude Code (הסוכן שבונה קוד ומסמכים), Git (מעקב אחרי שינויים), ו-VS Code (סביבת כתיבת קוד). זה עולם של שורת פקודה, והוא טכני בהרבה משלב 1.

אני משאיר את זה כאן כדי שתדע מה קיים ולאן זה הולך, לא בתור משימה. את מה שנצטרך מכאן נעשה יחד במפגש, על המסך, ובקצב שלך. אם בסוף מתברר שאתה לא צריך את זה בכלל - גם זו תשובה טובה.
