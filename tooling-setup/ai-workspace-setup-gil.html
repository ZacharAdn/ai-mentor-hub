קלוד דסקטופ - מה שראינו במפגש

מותקן כבר אצלך - כאן רק נזכרים במה שעשינו
קלוד דסקטופ היא האפליקציה של Claude שיושבת על המחשב עצמו, בלי דפדפן. אצלך היא כבר מותקנת, אז אין מה להתקין. במפגש עברנו עליה יחד, והקטעים הקצרים כאן צולמו מתוך המפגש עצמו - כדי שתוכל להיזכר בדיוק במה שעשינו.

מה שעשינו במפגש, שלב אחרי שלב:

  1. פותחים את קלוד דסקטופ, ולמעלה לוחצים על Code. זה הסוכן שיודע לעבוד בשבילך על קבצים אמיתיים במחשב. לא צריך לדעת לכתוב קוד - זה רק השם של הכלי.
    בסרטון: לוחצים למעלה על הכפתור Code - העיגול הירוק שציירתי במפגש מסמן אותו.
  2. בוחרים תיקייה לעבודה: מתחת לתיבת הכתיבה יש כפתור עם שם תיקייה, ליד המילה Local. לוחצים עליו, ובחלון שנפתח בוחרים את התיקייה שלנו - gil_stocks, זו שיצרנו במפגש.
    בתמונה: הכפתור מסומן באדום. אצלך יהיה כתוב עליו gil_stocks אחרי הבחירה הראשונה.
  3. חיבורים לשירותים שלך: בהגדרות של קלוד יש מסך בשם Connectors - בעברית: חיבורים. שם מחברים את קלוד לשירותים כמו גוגל דרייב או ג'ימייל. במפגש ראית שאצלי גוגל דרייב כבר מחובר (מסומן בוי).
    בסרטון: נכנסים להגדרות, לוחצים בצד על Connectors, ורואים את רשימת החיבורים - כל חיבור אפשר לנתק בכל רגע.
  4. אישור לפני כל פעולה: במצב Manual (ידני), הסוכן עוצר לפני כל פעולה במחשב, מסביר מה הוא רוצה לעשות, ומחכה. רק אחרי שלוחצים Allow once (אשר פעם אחת) הוא ממשיך.
    בסרטון: הסוכן שואל אם מותר לו להריץ פעולה, אני לוחץ אישור - ורק אז הוא מתחיל לעבוד.
  5. המצב הזה נקרא Manual והוא ברירת המחדל: הכפתור נמצא למטה משמאל, מתחת לתיבת הכתיבה. יש מצבים נוספים שבהם הסוכן מקבל יותר חופש - בינתיים נשארים על Manual, המצב הכי בטוח, וכל השאר נלמד יחד בהמשך.
    בתמונה: לחיצה על הכפתור למטה משמאל פותחת את התפריט - מוודאים שמסומן Manual.
התשובה לשאלה ששאלת במפגש

שאלת אם הסוכן יכול לעשות דברים בלי בקרה. כל עוד המצב הוא Manual - כל פעולה במחשב מחייבת אישור שלך לפני שהיא קורית. ואם משהו לא מסתדר או לא נראה כמו בסרטונים - עצור וכתוב לי, נעבור על זה יחד.

2

התקנת אובסידיאן

כ-5 דקות
אובסידיאן היא מחברת דיגיטלית שמורכבת מקבצים פשוטים במחשב שלך. אנחנו נשתמש בה כ"זיכרון" של המערכת: כאן יישמרו הנתונים, ההגדרות והידע שהסוכן צובר. הכל נשאר אצלך במחשב.

עקוב אחרי השלבים:

  1. פתח את הקישור obsidian.md (נפתח בטאב חדש), ולחץ על כפתור ההורדה הגדול
  2. ההורדה מזהה לבד את סוג המחשב שלך. הרץ את הקובץ שהורד ואשר את ברירות המחדל
  3. פתח את אובסידיאן. במסך הפתיחה בחר Open folder as vault (פתיחת תיקייה קיימת ככספת) - לא Create new vault
  4. נווט אל התיקייה שהכנו יחד במפגש (זו שקלוד יצר), בחר אותה ואשר
  5. זהו - אובסידיאן מציג את התיקייה הקיימת, וכל מה שקלוד יוצר בה מופיע אצלך אוטומטית
מה זו "כספת" (vault)?

פשוט תיקייה במחשב שאובסידיאן מנהל. כל מה שנכתוב שם הוא קבצים רגילים שלך, לא בענן של אף אחד. אתה הבעלים המלא של הזיכרון הזה.

מצוין, סיימת את שלב 1

קלוד דסקטופ ואובסידיאן מותקנים. זה כל מה שצריך למפגש הראשון.

עוד דבר אחד קטן, ואז סיימת

הגדרת פרטיות אחת ששווה לעשות עכשיו, לפני שאנחנו עובדים על נתוני התיק שלך.

שמור שהמידע שלך פרטי

דקה
כברירת מחדל, השיחות שלך עשויות לשמש לשיפור המודל. אתה עובד עם נתוני תיק אישיים, אז כדאי לכבות את זה.

עקוב אחרי השלבים:

  1. פתח את הקישור ההגדרות של קלוד (נפתח בטאב חדש)
  2. עבור ללשונית Privacy (פרטיות)
  3. כבה את האפשרות Help improve Claude. זהו, הנתונים שלך נשארים פרטיים

מה זה, ולמה זה כאן

ההתקנות בשלב הזה הן Node.js (מנוע הרצה), Claude Code (הסוכן שבונה קוד ומסמכים), Git (מעקב אחרי שינויים), ו-VS Code (סביבת כתיבת קוד). זה עולם של שורת פקודה, והוא טכני בהרבה משלב 1.
