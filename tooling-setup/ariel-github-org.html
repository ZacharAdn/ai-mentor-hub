מוסיפים את המייל של אריאל לחשבון GitHub

כ-3 דקות · מי שנרשם ל-GitHub עם המייל של אריאל מדלג
ההזמנה לארגון נשלחה למייל של אריאל. GitHub מאפשר לאשר אותה רק מחשבון שהמייל הזה מאומת בו. מי שנרשם עם מייל פרטי מוסיף את המייל של אריאל כמייל נוסף, וזה הכול.
  1. היכנסו ל-github.com/settings/emails (בתפריט: Settings ואז Emails).
  2. תחת Add email address הקלידו את המייל שלכם ב-msmail.ariel.ac.il ולחצו Add.
  3. פתחו את תיבת הדואר של אריאל ולחצו על קישור האימות ש-GitHub שלח.
  4. חזרו לדף Emails ובדקו שליד המייל של אריאל לא כתוב Unverified.
ℹ️ המייל הראשי לא משתנה
המייל הפרטי נשאר הראשי, וההתראות ממשיכות להגיע אליו. המייל של אריאל רק מאפשר לאשר את ההזמנה.

מי שבתפקיד המתכנת פותח ריפו בארגון

כ-3 דקות · פעם אחת לצוות
ריפו אחד לכל צוות, בתוך הארגון ולא בחשבון הפרטי. שאר חברי הצוות מחכים לשלב 4.
  1. היכנסו ל-github.com/organizations/Ariel-Vibe-Algorithm/repositories/new.
  2. בשדה Owner בדקו שכתוב Ariel-Vibe-Algorithm, ולא שם המשתמש שלכם.
  3. תנו שם קצר באנגלית לפרויקט, למשל caffeine-sleep, ובחרו Private.
  4. סמנו Add a README file ולחצו Create repository.
  5. בריפו החדש: Settings ואז Collaborators and teams. לחצו Add people, והוסיפו כל חבר צוות לפי שם המשתמש שלו ב-GitHub, עם הרשאת Write.
⚠️ כבר יש לכם ריפו פרטי?
פותחים בכל זאת ריפו בארגון, ומעבירים אליו את ה-README. כך כל הצוותים במקום אחד, ואלי וזכר רואים את כולם.
4

כל אחד משבט (Clone) את הריפו ל-VS Code

כ-3 דקות
שיבוט מוריד עותק של הריפו למחשב, ושומר אותו מחובר ל-GitHub.
  1. בדף הריפו ב-GitHub לחצו על הכפתור הירוק Code, והעתיקו את הכתובת שמתחת ל-HTTPS.
  2. ב-VS Code לחצו ‎Ctrl+Shift+P‎ (במק ‎Cmd+Shift+P‎), הקלידו Git: Clone, והדביקו את הכתובת.
  3. בחרו תיקייה במחשב, ובסוף לחצו Open.
⚠️ Clone, לא Publish
אם VS Code מציע Publish to GitHub, לא לוחצים. הכפתור הזה פותח ריפו חדש בחשבון הפרטי שלכם, ולא מחובר לריפו של הצוות. זה מה שהשתבש במחזור הקודם.
5

השינוי הראשון: קובץ עם השם שלכם

כ-4 דקות
כל אחד יוצר קובץ משלו, כדי ששני אנשים לא יערכו את אותה שורה באותו זמן.
  1. בתיקייה ב-VS Code צרו קובץ חדש בשם שלכם באנגלית, למשל dana.md, וכתבו בו שורה אחת: התפקיד שלכם בצוות.
  2. שמרו (‎Ctrl+S‎).
  3. פתחו את Source Control, האייקון של הענף בסרגל הצד. הקובץ מופיע תחת Changes.
  4. כתבו הודעה קצרה בשדה שלמעלה, למשל add dana, ולחצו Commit.
  5. לחצו Sync Changes. אם VS Code שואל, אשרו את ההתחברות ל-GitHub בדפדפן.
  6. רעננו את דף הריפו ב-GitHub. הקובץ שלכם שם.
💡 הדחיפה נדחתה?
חבר צוות דחף לפניכם. זה תקין: לוחצים שוב Sync Changes, ו-VS Code מושך קודם את השינוי שלו ואז דוחף את שלכם.
ℹ️ אותו דבר בטרמינל
git add . git commit -m "add dana" git pull git push
