  1. הקלד ולחץ Enter:
    git config --global user.name "Uri Shchori"
  2. הקלד ולחץ Enter, כשבמקום המייל לדוגמה יופיע המייל שאיתו נרשמת לגיטהאב בשלב 1:
    git config --global user.email "your-email@gmail.com"
  3. לבדיקה, הקלד ולחץ Enter:
    git config --global --list

בפלט של הפקודה השלישית מופיעות שתי שורות: user.name=Uri Shchori ו־user.email=… עם המייל שלך.
