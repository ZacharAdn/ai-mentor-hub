מדריך התקנת Claude Code

מדריך פשוט וידידותי להתקנת Claude Code — שלבים 1-6 מותאמים ל-Windows, ולמשתמשי Mac יש קיצור דרך של פקודה אחת. אין צורך בניסיון טכני קודם!

זמן משוער: 15-20 דקות

משתמשים ב-Mac? דלגו לקיצור הדרך ל-Mac — שלבים 1-3 לא רלוונטיים אצלכם.

לפני שמתחילים

  • W
    Windows 10 או 11
  • $
    מנוי Claude Pro או Team
🍎

על Mac? קיצור דרך — פקודה אחת

דלגו על שלבים 1, 2, 3
ב-macOS אין צורך ב-Node.js או ב-Git כדי להריץ את Claude Code — הוא מותקן כקובץ בינארי טבעי. פקודה אחת בטרמינל מחליפה את כל שלושת השלבים הראשונים, ואז מדלגים ישר לשלב 4 (התחברות) ולשלב 5 (VS Code).

איך עושים את זה:

  1. פתחו את Terminal (קיצור: Cmd+Space → הקלידו "terminal" → Enter)
  2. הדביקו את הפקודה הבאה ולחצו Enter:
curl -fsSL https://claude.ai/install.sh | bash
  1. חכו דקה-שתיים עד שההתקנה מסתיימת
  2. בדקו שזה עבד — הקלידו claude --version. אם מופיע מספר גרסה, מצוין
  3. עברו ישר ל-שלב 4 (הגדרה והתחברות) למטה
מה הפקודה עושה?

היא מורידה את Claude Code כקובץ בינארי מותאם ל-Mac (לא חבילת npm) — לכן לא צריך Node.js. גם Git לא נדרש להתקנה עצמה (הוא שימושי אם תרצו לעבוד עם repos של GitHub בעתיד, אבל זה לא חיוני להתחלה).

שאר המדריך — מה רלוונטי ל-Mac?

שלבים 1, 2, 3 ייעודיים ל-Windows — דלגו עליהם. שלב 4 (התחברות), שלב 5 (VS Code/Cursor), ו-שלב 6 (פרטיות) — זהים לחלוטין ב-Mac, פשוט תזכרו שהקיצורים שונים: Cmd במקום Ctrl.

1

התקנת Node.js

כ-2 דקות
Node.js היא סביבת הריצה שמפעילה את Claude Code. זו תוכנה חינמית שמשמשת מפתחים רבים.
התקנת Node.js בווינדוס

עקבו אחרי השלבים הבאים:

  1. פתחו את הדפדפן וחפשו "Node js" בגוגל
  2. לחצו על האתר הרשמי (nodejs.org)
  3. לחצו על הכפתור הירוק "LTS" להורדה (זו הגרסה היציבה)
  4. הריצו את הקובץ שהורדתם (שם הקובץ מסתיים ב-.msi)
  5. לחצו על "Next" באשף ההתקנה
  6. אשרו את הסכם הרישיון
  7. השאירו את תיקיית ההתקנה כברירת מחדל
  8. חשוב: אל תסמנו את האפשרות "Automatically install necessary tools" - השאירו אותה ריקה
  9. לחצו על "Install" והמתינו לסיום
  10. לחצו על "Finish"
איך יודעים שזה עבד?

פתחו Command Prompt והקלידו node --version. אם מופיע מספר (כמו v24.12.0), הכל בסדר!

2

התקנת Claude Code

כדקה
עכשיו נתקין את Claude Code עצמו באמצעות פקודה פשוטה ב-Command Prompt.
התקנת Claude Code דרך Command Prompt

עקבו אחרי השלבים הבאים:

  1. לחצו על תפריט התחל (אייקון החלון)
  2. הקלידו "cmd" או "Command Prompt"
  3. לחצו על Command Prompt כדי לפתוח אותו
  4. העתיקו והדביקו את הפקודה הזו, ולחצו Enter:
npm install -g @anthropic-ai/claude-code
מה הפקודה הזו עושה?

היא אומרת ל-Node.js להוריד ולהתקין את Claude Code מהאינטרנט. ה--g אומר "התקן גלובלית" כדי שתוכלו להשתמש בזה מכל מקום.

3

התקנת Git

כ-3 דקות
Git היא תוכנה חינמית שעוזרת לעקוב אחרי שינויים בקבצים. Claude Code צריך אותה כדי לעבוד כמו שצריך.
הורדה והתקנה של Git

עקבו אחרי השלבים הבאים:

  1. חפשו "git scm" בגוגל
  2. היכנסו לאתר הרשמי של Git (git-scm.com)
  3. לחצו על "Download for Windows"
  4. בחרו ב-"64-bit Git for Windows Setup" (Standalone Installer)
  5. הריצו את קובץ ההתקנה שהורדתם
  6. לחצו על "Next" ברוב האפשרויות (ברירות המחדל מצוינות)
אל תדאגו מהאפשרויות!

למתקין של Git יש הרבה מסכים עם אפשרויות טכניות. פשוט לחצו "Next" והשאירו את ברירות המחדל - הן עובדות מצוין עם Claude Code.

סיכום מהיר של אפשרויות Git (פשוט לחצו Next):

  1. עורך: Vim (ברירת מחדל) - זה בסדר
  2. ענף ברירת מחדל: תנו ל-Git להחליט
  3. סביבת PATH: "Git from command line and 3rd-party software" (מומלץ)
  4. SSH: השתמשו ב-OpenSSH המובנה
  5. HTTPS: השתמשו ב-Windows Secure Channel
  6. סיומי שורות: Checkout Windows-style, commit Unix-style
  7. טרמינל: השתמשו ב-MinTTY
  8. לבסוף, לחצו על "Install"
4

הגדרה והתחברות

כ-3 דקות
הגיע הזמן להפעיל את Claude Code ולחבר אותו לחשבון Claude שלכם. כאן מתחיל הקסם!
הפעלת Claude Code והתחברות

עקבו אחרי השלבים הבאים:

  1. צרו תיקייה חדשה לפרויקט (למשל, קליק ימני על שולחן העבודה ← חדש ← תיקייה ← קראו לה "test")
  2. פתחו את PowerShell או Command Prompt
  3. נווטו לתיקייה שלכם על ידי הקלדת cd Desktop\test (או הנתיב לתיקייה שלכם)
  4. הקלידו claude ולחצו Enter
  5. השתמשו בחיצים כדי לבחור ערכת נושא (כמו Dark mode) ולחצו Enter
  6. בחרו ב-"Claude account with subscription"
  7. ייפתח חלון דפדפן - התחברו לחשבון Claude שלכם
  8. לחצו על "Authorize" כדי לחבר את Claude Code
  9. תראו "You're all set up" - אפשר לסגור את הדפדפן
  10. חזרו לטרמינל, קראו את אפשרויות הפרטיות ולחצו Enter לאישור
צריכים מנוי?

אתם צריכים מנוי Claude Pro או Team. אם אין לכם, הדפדפן יציע לכם לשדרג. המנויים מתחילים מ-$20 לחודש.

מזל טוב!

Claude Code מוכן לשימוש! אתם יכולים להתחיל לשוחח עם Claude בטרמינל.

5

שילוב ב-VS Code או Cursor

כ-5 דקות
עד עכשיו Claude Code עובד מהטרמינל בלבד. עכשיו נחבר אותו ל-VS Code (או Cursor) — סביבת קוד עם פאנל צ'אט ייעודי וגישה לקבצים בלחיצה. השלבים זהים ב-Windows וב-macOS, ההבדל היחיד הוא הקיצורים.

שלב א — התקנת VS Code (דלגו אם כבר מותקן):

  1. גלשו ל-code.visualstudio.com ולחצו על כפתור ההורדה הגדול
  2. Windows: בחרו "User Installer (64-bit)". macOS: בחרו "Apple Silicon" אם המעבד M1/M2/M3, אחרת "Intel"
  3. הריצו את הקובץ שהורד, אשרו את ברירות המחדל ולחצו Install
  4. פתחו את VS Code כשההתקנה מסתיימת
משתמשים ב-Cursor?

Cursor מבוסס על VS Code — אותה חנות תוספים, אותם קיצורים. דלגו ישר לשלב ב' למטה.

שלב ב — התקנת התוסף Claude Code for VS Code:

  1. פתחו את חלונית ה-Extensions: Ctrl+Shift+X ב-Windows / Cmd+Shift+X ב-macOS (או לחצו על אייקון 4 הריבועים בסרגל הצד השמאלי)
  2. הקלידו Claude Code בשורת החיפוש
  3. בחרו את התוסף "Claude Code for VS Code" מטעם Anthropic (סימן וי כחול ליד השם — זה ה-publisher הרשמי)
  4. לחצו על Install
חיפוש והתקנת התוסף הרשמי של Anthropic

שלב ג — הפעלה ראשונה:

  1. פתחו תיקיית פרויקט: File → Open Folder (קיצור: Ctrl+K Ctrl+O ב-Windows / Cmd+O ב-macOS)
  2. פתחו קובץ מתוך התיקייה — לחצו על קובץ כלשהו ב-Explorer (למשל README.md). זה חשוב — אייקון Claude מופיע רק כשיש קובץ פתוח בעורך
  3. הסתכלו על הפינה הימנית-עליונה של חלון העורך (לא בסרגל הצד השמאלי) — תראו אייקון של "פיצוץ" כתום-אדום. זה Claude
  4. לחצו עליו — ייפתח פאנל הצ'אט של Claude, מחובר אוטומטית לחשבון שלכם (לא צריך להזין סיסמה שוב — השלמתם זאת בשלב 4)
  5. נסו פקודה ראשונה — לדוגמה: "תסכם לי מה יש בתיקייה הזאת"
אייקון Claude בפינה הימנית-עליונה של העורך (מסומן באדום) — מופיע רק כשיש קובץ פתוח
לא רואים את האייקון?

סביר שעדיין לא פתחתם קובץ. ה-VS Code מציג את האייקון רק כשיש לשונית עורך פעילה. פתחו כל קובץ מהתיקייה (אפילו ריק) והאייקון יופיע מיד.

דרך חלופית — בלי תוסף

אם תעדיפו טרמינל פנימי במקום פאנל ייעודי — פתחו טרמינל מובנה ב-VS Code עם Ctrl+` (Windows) או Cmd+` (macOS), והקלידו claude. אותה חוויה כמו ב-Command Prompt, רק שמשולבת ב-IDE שלכם.

6

הגדרות פרטיות אופציונלי

כדקה
כברירת מחדל, השיחות שלכם עשויות לשמש לשיפור Claude. אם אתם מעדיפים יותר פרטיות, אפשר לשנות את ההגדרה הזו.
ניהול הגדרות פרטיות

כדי לבטל שימוש בנתונים לאימון:

  1. פתחו את הדפדפן וגלשו ל-claude.ai
  2. לחצו על אייקון הפרופיל שלכם בפינה העליונה
  3. לחצו על "Settings"
  4. עברו ללשונית "Privacy"
  5. כבו את האפשרות "Help improve Claude"
מה זה אומר?

כש-"Help improve Claude" מופעל, השיחות שלכם עשויות להיבדק על ידי Anthropic כדי לשפר את Claude. כיבוי האפשרות אומר שהנתונים שלכם נשארים פרטיים ולא ישמשו לאימון.

בונוס - לגרום ל-Claude להיות אובייקטיבי:

אפשר להגדיר ל-Claude להיות ישיר ואובייקטיבי, במקום להסכים אתכם אוטומטית. ב-Claude Desktop, פתחו Settings, אחר כך General, ושם Instructions for Claude, והדביקו את הטקסט הבא:

Never tell me what I want to hear. I want you to look at things objectively, contradict me when needed. If you think otherwise, go with your strong opinion.

נבנה באהבה — הבסיס נלקח מאביץ (אברהם יצחק מאיר)
