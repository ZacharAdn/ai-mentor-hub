גיטהאב לסוכן שלך

פותחים חשבון, מתקינים גיט, ונותנים לסוכן לגבות כל יום את הסקילים והזיכרון העסקי שבנית, כדי ששום דבר לא ילך לאיבוד.

⏱️ כרבע שעה · ווינדוס · מתוך אפליקציית ChatGPT
1

לפתוח חשבון גיטהאב

כשלוש דקות
🛑 נרשמים רק באתר הרשמי
הכתובת היחידה היא github.com. בדוק אותה בשורת הכתובת למעלה. אל תיכנס דרך פרסומת בגוגל, ואל תוריד שום אפליקציה. גיטהאב חינמי לגמרי: אם מבקשים ממך כרטיס אשראי, אתה במקום הלא נכון.
  1. גש ל־github.com/signup (לחיצה על הקישור הזה מביאה אותך לאתר הנכון).
  2. הזן מייל שאתה באמת בודק, כי יגיע לשם קוד אימות.
  3. בחר סיסמה ושמור אותה.
  4. בחר שם משתמש באנגלית, פשוט, עם השם שלך.
  5. הזן את הקוד שהגיע למייל, ובחר את התכנית החינמית (Free).
⚠️ קיבלת מסך "הגישה מוגבלת זמנית"
זו חסימה אוטומטית של גיטהאב, לא משהו שעשית. מה שהכי עובד: לכבות את הוויי-פיי, לחבר את המחשב לשיתוף אינטרנט מהנייד, ולנסות שוב. אפשר גם לנסות בעוד רבע שעה.
2

לפתוח טרמינל בתוך אפליקציית ChatGPT, ולבדוק אם גיט מותקן

שתי דקות
טרמינל הוא חלון שבו מקלידים פקודות. לא צריך תוכנה נוספת, יש אחד בתוך אפליקציית ChatGPT שאתה כבר עובד בה.
  1. פתח את אפליקציית ChatGPT במחשב, בלשונית Codex שבה אתה עובד עם הסוכן.
  2. בפינה הימנית העליונה, לחץ על הכפתור New tab (ריבוע עם פלוס).
  3. בחלון שנפתח בצד, תחת Tools, לחץ על Terminal.
  4. בטרמינל שנפתח, הקלד (או העתק עם הכפתור והדבק עם Ctrl+V) ולחץ Enter:
    git --version
✅ קיבלת שורה שמתחילה ב־git version
גיט כבר מותקן. דלג ישר לשלב 4. מספר הגרסה עצמו לא משנה.
⚠️ קיבלת הודעה אדומה עם המילים is not recognized
גיט לא מותקן. המשך לשלב 3.
3

להתקין את גיט (רק אם שלב 2 לא עבד)

כחמש דקות
את זה עושים ידנית, הסוכן לא יכול ללחוץ בשבילך. גם כאן מורידים רק מהאתר הרשמי.
  1. גש ל־git-scm.com/download/win
  2. לחץ על Click here to download.
  3. פתח את הקובץ שירד והרץ אותו. אם ווינדוס שואל "לאפשר לאפליקציה לבצע שינויים", לחץ כן.
  4. לחץ Next על כל המסכים, ובסוף Install. ברירות המחדל טובות.
⚠️ מסך אחד לבדוק בדרך: Adjusting your PATH environment
יש בו שלוש אפשרויות. ודא שמסומנת האמצעית (בדרך כלל היא כבר מסומנת). רק איתה הטרמינל יזהה את גיט.
איור להמחשה של המסך הזה
Use Git from Git Bash only
Git from the command line and also from 3rd-party software זו האפשרות
Use Git and optional Unix tools from the Command Prompt
💡 אחרי שההתקנה נגמרה
סגור את אפליקציית ChatGPT לגמרי ופתח אותה מחדש. אפליקציה שהייתה פתוחה בזמן ההתקנה עוד לא מכירה את גיט. אחר כך פתח שוב טרמינל (כמו בשלב 2) והרץ שוב git --version. אם גם עכשיו זה לא עובד, עשה ריסטארט למחשב.
4

להגיד לגיט מי אתה

שתי דקות
שלוש פקודות באותו טרמינל. הראשונות שתיים מגדירות, השלישית בודקת.
  1. העתק, הדבק בטרמינל ולחץ Enter:
    git config --global user.name "Paz Ben Dakon"
  2. העתק והדבק, אבל לפני Enter תחליף את המייל לדוגמה במייל שאיתו נרשמת לגיטהאב בשלב 1:
    git config --global user.email "your-email@gmail.com"
  3. לבדיקה, העתק, הדבק ולחץ Enter:
    git config --global --list
✅ איך יודעים שזה עבד
בפלט של הפקודה השלישית מופיעות שתי שורות: user.name=Paz Ben Dakon ו־user.email=… עם המייל שלך.
⚠️ שתי נקודות שמפילות את זה
המרכאות חייבות להישאר, והשם רק באנגלית. אם המקלדת עברה לעברית באמצע, מחק ותקליד שוב.
5

ליצור ריפו פרטי בגיטהאב

שתי דקות
ריפו הוא תיקייה בענן של גיטהאב. לשם הסוכן יגבה את העבודה שלך.
  1. גש ל־github.com/new (מחובר עם החשבון משלב 1).
  2. בשדה Repository name כתוב: paz-agent
  3. בחר Private. זה הכי חשוב בשלב הזה.
  4. אל תסמן שום דבר אחר (לא README ולא שום תוספת), ולחץ על הכפתור הירוק Create repository.
  5. תגיע לעמוד של הריפו. העתק את הכתובת משורת הכתובת של הדפדפן. היא נראית ככה: https://github.com/your-username/paz-agent (במקום your-username יופיע שם המשתמש שלך)
🛑 למה דווקא Private
בריפו יהיו הסקילים, הזיכרון העסקי ושמות של לקוחות. ריפו Public פתוח לכל העולם. Private רק אתה רואה.
6

לבקש מהסוכן לגבות הכול, כל יום

כחמש דקות
מכאן הסוכן עושה את העבודה. ההנחיה הולכת לשיחה עם הסוכן בלשונית Codex, לא לטרמינל.
  1. פתח שיחה חדשה עם הסוכן.
  2. לחץ על העתק בהנחיה למטה, והדבק אותה בשיחה.
  3. בסוף ההנחיה, אחרי המילים "הלינק לריפו", הדבק את הכתובת שהעתקת בשלב 5, ושלח.
יצרתי ריפו פרטי בגיטהאב, ואני רוצה שתגבה אליו כל יום את כל מה שבנינו: הסקילים, הזיכרון העסקי, ההגדרות וההוראות שלך. כלל ראשון לפני הכול: אסור שיעלו לגיטהאב סיסמאות, טוקנים או מפתחות. קובץ החיבורים, קבצי env, הטוקן של Green API והמפתח והסוד של מורנינג נשארים רק אצלי במחשב. תוסיף אותם ל־gitignore. לפני הגיבוי הראשון תראה לי את רשימת הקבצים שעומדים לעלות, ותחכה לאישור שלי. אחרי שהגיבוי הראשון הצליח, תגדיר אוטומציה שמגבה הכול לגיטהאב פעם ביום, ותעדכן אותי אם גיבוי נכשל. הלינק לריפו:
💡 מה יקרה עכשיו
הסוכן יעצור כמה פעמים ויבקש אישור להריץ פקודות, וזה תקין. קרא כל בקשה ואשר. בפעם הראשונה שהוא מעלה לגיטהאב, ייתכן שייפתח חלון התחברות לגיטהאב: התחבר עם החשבון משלב 1 ואשר.
⚠️ כשהוא מראה לך את רשימת הקבצים
עבור עליה לפני שאתה מאשר. אם אתה רואה שם קובץ חיבורים, קובץ שמסתיים ב־.env, או משהו עם המילים token, key או secret, אל תאשר. כתוב לו "תוציא את זה" ותשלח לי צילום מסך.
האוטומציה רצה רק כשהמחשב דלוק, כמו שאר האוטומציות שלך. אם המחשב היה כבוי, הגיבוי פשוט ירוץ בפעם הבאה.
